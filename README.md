# ♻️ EcoAcess Manaus: Identificação sem Barreiras

![Banner EcoAcess Manaus](https://raw.githubusercontent.com/jotamarks18faculdade/EcoAcessManaus/master/Captura%20de%20tela%202026-10-26%20034603.jpg)

O **EcoAcess Manaus** é uma solução tecnológica móvel voltada a promover a **acessibilidade digital**, a **inclusão social** e a **sustentabilidade ambiental** na cidade de Manaus (AM). O projeto integra Inteligência Artificial (IA), Teoria dos Grafos e Design Inclusivo para solucionar os desafios de descarte incorreto de resíduos e apoiar pessoas com deficiência na visão de cores (daltonismo).

---

## 📌 Eixos do Projeto

1. **🤖 IA e Visão Computacional (*On-Device*)**
   * Classificação automatizada de resíduos a partir da câmera do smartphone usando **TensorFlow Lite** (MobileNetV3 / EfficientNet)[cite: 2].
   * Identificação de categorias como: *Papel*, *Plástico*, *Metal*, *Vidro*, *Eletrônicos* e *Orgânico*[cite: 2].

2. **🗺️ Teoria dos Grafos e Geolocalização**
   * Recomendação de Pontos de Entrega Voluntária (PEVs) e ecopontos em Manaus[cite: 2].
   * Cálculo de caminhos mínimos otimizados utilizando o **Algoritmo de Dijkstra** / **A\*** integrados com **PostGIS** e **Node.js**[cite: 2].

3. **👁️‍🗨️ Acessibilidade Cromática e Multimodal**
   * Aplicação do sistema **ColorADD** (código de símbolos para cores)[cite: 2].
   * Conformidade com as diretrizes **WCAG 2.1 (AA)**: alto contraste, padrões texturizados, textos descritivos e retorno sonoro/vibratório[cite: 2].

---

## 🛠️ Tecnologias Utilizadas

* **Mobile / Frontend:** React Native (Expo), TypeScript, Context API / Zustand[cite: 2].
* **Backend:** Node.js, Express.js, Redis[cite: 2].
* **Banco de Dados:** PostgreSQL com extensão PostGIS[cite: 2].
* **Inteligência Artificial:** TensorFlow Lite, Python (NetworkX / Graphology)[cite: 2].

## 🎯 Impacto Socioambiental (ODS Agenda 2030)

* **ODS 11 - Cidades e Comunidades Sustentáveis:** Facilita a conexão do cidadão com os pontos de coleta seletiva da cidade[cite: 2].
* **ODS 13 - Ação Contra a Mudança Global do Clima:** Estimula a destinação correta de resíduos, contribuindo para a redução da emissão de gases de efeito estufa em aterros[cite: 2].
